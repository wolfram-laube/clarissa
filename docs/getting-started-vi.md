# Bắt đầu với CLARISSA

CLARISSA là hệ thống AI hỗ trợ mô phỏng hồ chứa.

- Python 3.11+
- Truy cập OPM Flow hoặc ECLIPSE

## Cài đặt

pip install clarissa
