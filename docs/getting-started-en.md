# Getting Started with CLARISSA

> 🚧 **Under Construction** - This guide is being developed.

## Quick Overview

CLARISSA (Conversational Logic for Automated Reservoir Inference and Simulation Assistance) is an AI-powered system for reservoir simulation.

## Prerequisites

- Python 3.11+
- Access to OPM Flow or ECLIPSE simulator

## Installation

```bash
pip install clarissa
```
