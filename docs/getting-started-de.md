## Überblick

CLARISSA (Conversational Logic for Automated Reservoir Inference and Simulation Assistance) ist ein KI-gestütztes System für Reservoir-Simulation.

## Voraussetzungen

- Python 3.11+
- Zugang zu OPM Flow oder ECLIPSE Simulator

## Installation

```bash
pip install clarissa
```
